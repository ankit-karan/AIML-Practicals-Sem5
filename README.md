# AIML Practicals – Semester 5

This repository contains the Artificial Intelligence and Machine Learning (AIML) practical implementations performed as part of the Semester 5 curriculum.

All practicals were implemented and executed using Google Colab and are provided as Jupyter Notebook (`.ipynb`) files.

## Experiments

| Experiment | Practical |
|------------|-----------|
| 1 | Association Between Dependent and Independent Variables |
| 2 | Clustering Techniques Using Unsupervised Learning |
| 3 | Dimensionality Reduction Using Principal Component Analysis (PCA) |
| 4 | Naive Bayes Classification |
| 5 | K-Nearest Neighbors (KNN) Algorithm |
| 6 | Linear Regression Algorithm |
| 7 | Support Vector Machine (SVM) for Regression |
| 8 | Regularization to Avoid Overfitting |
| 9 | Object Detection on CCTV Footage |
| 10 | Fake News Detection from Multimodal Data |
